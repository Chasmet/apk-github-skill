# apk-github

Skill Grok pour compiler et publier une APK Android via GitHub Actions.

Grok ne fabrique pas l'APK dans le chat. Le runner Actions compile avec Gradle.

## Fichiers

- `SKILL.md` — workflow agent
- `assets/android-apk.yml` — template CI
- `references/` — outils, dépannage, repos Chasmet

## Usage dans Grok

Dire : « Relance l'APK de rush-studio » ou « Publie l'APK de Montage-vid-o- ».
